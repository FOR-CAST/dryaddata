# dryad_auth without credentials errors with guidance

    Code
      dryad_auth()
    Condition
      Error in `dryad_auth()`:
      ! Dryad client credentials are not set.
      i Preferred: run `dryad_set_credentials()` to store them in your OS keychain.
      i Or set `DRYAD_CLIENT_ID` and `DRYAD_CLIENT_SECRET` in '~/.Renviron'.
      i Create an application at <https://datadryad.org/account> (or the sandbox equivalent).
